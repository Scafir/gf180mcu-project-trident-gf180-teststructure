# trident-gf180-teststructures

The aim of this ASIC is to implement teststructures to experimentally measure
leakage for various basic teststructures such as (but not limited to):
* transistors
* MIM capacitors
* ESD protection pads

You can find the datasheet of this chip under `doc/TRIDENT_GF180_teststructures.pdf`.

ESD protection pads from liplib have been used, available here:
https://github.com/Scafir/liplib

This is an ASIC made through a CERN+JKU PhD collaboration.
